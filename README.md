# AILesson-Planner
第十六届中国大学生服务外包创新创业大赛参赛项目（后端）

---

## 项目简介
AILesson-Planner 是一个面向教育场景的智能教案与教学资源管理平台，集成了 AI 生成、课程管理、班级管理、文件存储、知识图谱等多种功能，助力教师高效备课与资源共享。

## 主要功能
- **用户系统**：注册、登录、找回密码、个人信息管理、邮箱验证、密码修改等。
- **课程与班级管理**：课程创建、查询、更新、删除，班级与学生信息管理。
- **智能教案生成**：基于 AI 能力自动生成单元设计、跨学科设计、作业、演讲稿、PPT、图片等多种教案内容。
- **教学资源管理**：支持文件上传、目录管理、资源收藏、回收站、资源分享与链接生成。
- **知识图谱**：支持课程内容、学生学习路径等知识图谱的生成与可视化。
- **成绩与题库管理**：学生成绩录入、导入导出、错题本、题目自动生成等。
- **资源分享与协作**：支持教学资源的分享、检索与协作。
- **WebSocket 实时通信**：支持实时问答与消息推送。

## 技术栈
- **后端语言**：Go
- **Web 框架**：go-zero
- **数据库**：MySQL
- **缓存**：Redis
- **全文检索**：Elasticsearch
- **对象存储**：MinIO
- **知识图谱**：Neo4j
- **AI 服务**：集成外部 AI 接口（如通义千问等）
- **文档处理**：Unidoc

## 快速启动
1. **环境准备**
   - Go 1.18+
   - MySQL、Redis、Elasticsearch、MinIO、Neo4j 等服务
2. **配置文件**
   - 复制 `etc/app.example.yaml` 为 `etc/app.yaml`，根据实际环境修改数据库、存储、AI 等配置。
3. **依赖安装**
   ```bash
   go mod tidy
   ```
4. **启动服务**
   ```bash
   go run app.go -f etc/app.yaml
   ```
